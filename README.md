# Hi, I'm Mehmet Can Ay 

I am a research software engineer at [Fraunhofer SCAI](https://www.scai.fraunhofer.de) working at the intersection of biomedical informatics, semantic harmoization, and full-stack software development.

I build Python APIs, Angular applications, PostgreSQL/pgvector retrieval systems, and containerized research software. My background combines molecular biology, life science informatics, biomedical ontologies, and software engineering.

## Selected Work

### Kitsune

Semantic-search and data-stewardship platform for mapping data dictionaries to biomedical terminology concepts using text embeddings.

**My contribution:** Software architecture, API and frontend development, database integration, and deployment workflows.

### PDataViewer

Full-stack application for exploring Parkinson's disease cohort data and assessing dataset suitability and interoperability.

**My contribution:** Application design, data modeling, backend and frontend development, cohort-data processing, and deployment.

### datastew

Python library for embedding-based data harmonization and semantic search using PostgreSQL and pgvector.

**My contribution:** Harmonization workflows, database and retrieval functionality, testing, and maintenance.
